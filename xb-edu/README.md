# 小白教育互动课件 · 离线版

把 [xbjiaoyu.com](https://xbjiaoyu.com/) 的互动课件复刻成**断网可用**的本地版本。

双击 `index.html` 即可使用：不联网、不登录、不装任何运行时。每个课件本身就是**单文件 HTML**，
可以单独拷走发给别人。

## 内容

| 学科 | 数量 | 课件 |
|---|---|---|
| 物理 | 24 | 平面镜成像（11 个细分）、透镜成像（6 个）、核能与核裂变（5 个）、折叠光屏、漫反射 |
| 化学 | 12 | 空气与氧气、空气的组成、氧气含量测定、催化剂、木炭/硫/铁丝燃烧、氧气检验、原子结构、离子形成、元素与质子数 |
| 地理 | 12 | 等高线与地形图全套（海拔、等高距、坡度、山峰盆地、山脊山谷、鞍部陡崖、剖面图、路线选择、判读） |
| 数学 | 5 | 观察物体、三视图、还原搭建 |

合计 **53 个课件 / 48.5 MB / 115 个文件**。

**范围说明**：原站共 550 个课件，`/api/catalog` 里 `mode` 字段区分 `free`(53) 与 `paid`(497)。
付费课件虽然也标记 `downloadable: true`，但 `/api/downloads/prepare` 会对未购买的产品拒绝签发下载地址，
所以能拿到文件的只有这 53 个。

## 目录结构

```

assets/covers/        53 张封面（原站封面图，转 webp）

_tools/               复刻工具链
```

## 复刻方法

这个站是传统静态站点 + JSON API，比 SPA 好处理。关键三步：

```bash
python _tools/fetch_courseware.py     # 拉全部免费课件（单文件 HTML）
python _tools/build_index.py          # 下封面 + 生成总览页
```

数据流：

1. `GET /api/catalog` — **匿名可访问**，774 KB，返回 550 个产品的完整元数据
   （标题、学科、学段、章节、封面、免费/付费、`canDownload`、`owned`）。用它当索引用，不用爬 HTML。
2. `POST /api/downloads/prepare {productId, confirmSelection:true}` — 签发一次性下载地址
   `{"url":"/api/downloads/file/<token>","filename":"平面镜成像.html","expiresAt":…}`，5 分钟过期。
3. `GET /api/downloads/file/<token>` — 返回**完整的单文件 HTML**（内联了全部 JS/CSS/图片/3D 数据）。

## 关键发现（踩过的坑）

1. **POST 必须同时带 `Origin` 和 `X-Requested-With: studio`**，缺任一个都返回
   `403 {"error":"请求来源不匹配，请重新打开网站"}`。只带 `X-Requested-With` 不够——`Origin`
   才是真正的校验项，这个错误信息很有误导性。
2. **下载地址 5 分钟过期且一次性**，所以必须「prepare → 立刻 GET」，不能先批量 prepare 再统一下载。
3. **课件是单文件自包含的**：53 个文件里 52 个零外部引用；`terrain` 里只有一个指向 usgs.gov 的
   说明性超链接（不是资源），离线无影响。
4. **封面图匿名可取**（`/images/course-covers-v13/*.png`，单张 130 KB–1.3 MB），不必走登录态。

## 已知限制

- 只有 53 个免费课件；付费 497 个需要购买，服务端不签发下载地址。
- 课件里的「导出画面」「反录演示」等按钮依赖浏览器能力，本地可用；若原站按钮走的是服务端接口，
  离线时点击会静默失败（不影响主流程）。
- 原站若更新课件版本，本地不会自动跟进，需要重跑 `fetch_courseware.py`。
